# Redshift Trading LLP

A 3D-first marketing website for Redshift Trading LLP — an ML/AI-powered medium frequency trading firm operating in Indian markets.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Three.js / React Three Fiber
- Framer Motion & GSAP
- shadcn/ui

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+ (or [Bun](https://bun.sh/))

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app runs at [http://localhost:8080](http://localhost:8080).

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
├── components/    # Reusable UI & 3D components
├── pages/         # Route pages (Index, Compliance, Careers, Contact)
├── hooks/         # Custom React hooks
├── lib/           # Utility functions
└── assets/        # Static assets
```

## Pages

- **Home** — 3D hero, scroll-driven narrative, services, markets, team
- **Compliance** — Regulatory disclosures & risk warnings (SEBI)
- **Careers** — Culture & hiring CTA
- **Contact** — Inquiry form
